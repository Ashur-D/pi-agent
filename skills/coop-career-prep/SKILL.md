# IT Co-op Career Preparation Guide

Framework for turning IT and networking coursework, labs, and projects into professional job application materials.

## 1. Transforming Lab Work into Resume Impact Bullets

Don't write what the professor assigned. Write what you engineered, the technologies used, and the measurable outcome.

- **Formula:** `[Strong Action Verb] + [Specific Technology/Protocol/Environment] + [Method/Action Taken] + [Result/Impact]`
- *Bad:* "Did labs on Windows Server and Active Directory."
- *Good:* "Configured Windows Server 2022 domain environment, creating automated PowerShell scripts to provision 50+ user accounts, assign RBAC permissions, and enforce security GPOs."
- *Bad:* "Wrote Python socket script."
- *Good:* "Built custom Python TCP/UDP client-server applications utilizing the socket library and Scapy to analyze network latency and packet loss across simulated subnets."

## 2. Technical Resume Structure for Students

1. **Header:** Clean contact info, GitHub, LinkedIn.
2. **Technical Skills:** Group by category:
   - *Networking & Protocols:* TCP/IP, DNS, DHCP, VLANs, Subnetting (CIDR/VLSM), OSPF, Wireshark, Packet Tracer.
   - *Operating Systems & Systems Administration:* Windows Server (Active Directory, GPO), Linux (Ubuntu, Debian, Bash).
   - *Programming & Scripting:* Python, PowerShell, Bash, Git.
   - *Security:* Firewalls (iptables/UFW), SSL/TLS, SSH, Port Scanning (Nmap).
3. **Projects / Academic Labs:** Treat major coursework labs as technical projects with bullet points detailing tools and outcomes.
4. **Education & Certifications:** Degree/Diploma program, expected graduation, CCNA/CompTIA progress.

## 3. STAR Method Interview Answers

Structure every behavioral and technical story:
- **Situation:** Set the context in 1-2 sentences (the lab, team project, or client scenario).
- **Task:** What was the specific goal or technical challenge?
- **Action:** Detail your individual technical contribution (the commands run, scripts written, or troubleshooting steps taken).
- **Result:** The successful outcome (e.g., "identified the misconfigured subnet mask in Wireshark, restoring full ping connectivity within minutes").
